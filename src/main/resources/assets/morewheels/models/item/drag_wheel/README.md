# drag_wheel

Retexture of the `steel_small_wheel` mesh: `block.obj` is byte for byte the same file,
only the texture differs.

| | |
|---|---|
| radius | 0.75 |
| rotation | `AXLE_Y` (90) - Blender mesh |
| minimum friction | 0.5 |
| mesh radius | 0.750 (1:1 with the registered radius) |
| mesh bounds | 1.5 x 0.6334 x 1.5 blocks |
| texture | `drag_tire`, 32x32 |

## Binary assets to upload by hand

- `block.obj` (same file as `../steel_small_wheel/block.obj`)
- `../../../textures/block/drag_wheel/drag_tire.png`
