# small-tractor_tire

The front-axle partner to `tractor_tire`: the identical mesh written out at 77.5% scale,
for a tractor whose rear axle runs the big one. Registered against Offroad's `tire` tier
at 0.96875.

## Files

| file | how it gets here |
| --- | --- |
| `block.obj` | binary, uploaded through the GitHub web UI |
| `block.mtl` | text |
| `item.json` | text |
| `../../../../textures/block/small-tractor_tire/tire_0.png` | binary, uploaded through the GitHub web UI |

`block.obj` and `tire_0.png` cannot go through the contents API, which takes a UTF-8
string, so they are uploaded separately from the text files.

## Geometry

Generated by the same `build_tractor.py` run that produces `tractor_tire`, with only the
target radius argument changed from 1.156 to 0.896 blocks. Topology, tread and atlas are
identical, so the chevrons stay in proportion and the pair reads as one set. See the
`tractor_tire` README for how the chevron tread is built and why it closes along the
axle.

- 1642 faces, 6456 vertices, quads only
- mesh radius 0.896 blocks against a registered radius of 0.96875, a 7.5% margin - the
  same mesh radius as `soviet_wheel` and `semi-truck_tire`
- bounds 1.792 x 0.6636 x 1.7897 blocks, width over diameter 0.37
- scale factor 1.6906 from the 16 px design space

## Texture

The same 64x64 atlas as `tractor_tire`: carcass rubber, rim red, groove shadow, dark rim
metal and worn tread crown in five 16x16 tiles. `item.json` sets `flip_v: true`, so the
OBJ stores v bottom-up.

## Checks

Same build-time and render checks as `tractor_tire`: quads only, verified tread closure,
no lug overhang past the sidewall, no coplanar caps, and zero see-through pixels from
six camera angles front and back.
